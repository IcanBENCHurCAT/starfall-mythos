# Free sprite sheet & asset sources

Vetted 2026-10-03. Recheck each page's license before shipping a commercial game;
licenses below are what the source claims today, not legal advice.

| Source | URL | License | Best for |
|---|---|---|---|
| Kenney | https://kenney.nl/assets | CC0 (20,000+ assets, no signup) | Prototyping everything; packs share a style so they mix |
| OpenGameArt | https://opengameart.org | Mixed (filter by license) | The big archive; check each item |
| Liberated Pixel Cup | https://lpc.opengameart.org | CC-BY / CC-BY-SA mostly | SNES-era top-down RPG sets |
| LPC character generator | https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator | Mixed per-asset | Custom 4-dir characters with full anim sets |
| itch.io CC0 tag | https://itch.io/game-assets/new-and-popular/tag-cc0 | CC0 | Fresh indie packs |
| Superpowers asset packs | https://github.com/sparklinlabs/superpowers-asset-packs | CC0 | Bundled in `assets/third-party/` already |
| Mozilla BrowserQuest | https://github.com/mozilla/BrowserQuest | CC-BY-SA 3.0 (art) | Hundreds of fantasy sprites |

## Already in this project

`assets/third-party/superpowers-medieval-fantasy/` (CC0, LICENSE.txt kept):
characters, monsters, animals, background-elements, items, fx, hud, sounds, music.
Top-down 16-bit style, matches this engine's 16x16 tile / 32x32 sprite contract.

## Manifest rule

Every third-party file gets one line: file, author, license, source URL, date checked.
Copy `ASSET_MANIFEST.template.md` next to any new pack you add.
